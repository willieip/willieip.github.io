# Seward Park

An interactive park diorama with day and night lighting, gentle wind, keyboard navigation, and an OBJ download.

[Open the viewer](https://willieip.me/seward-park/) · [Editable website source](source/)

![Park preview](screenshot.jpeg)

To rebuild, open the source folder, install dependencies, and run `pnpm build:pages`. Copy the resulting `out` files into this folder while retaining `source`.
